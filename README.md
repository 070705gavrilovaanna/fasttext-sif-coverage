# Сравнение FastText и SIF для оценки покрытия статьи тезисами

## Описание задачи

Оценить, насколько выбранный набор тезисов покрывает содержание статьи.

**Входные данные:**
- Статья (текст)
- Полный список тезисов по статье
- Индексы выбранных тезисов

**Выходные данные:**
- Coverage - число от 0 до 1

---

## Реализованные методы

### 1. FastText embeddings

Используется предобученная модель **fasttext** (`cc.ru.300.bin`) - векторы слов для русского языка, обученные на Common Crawl.

- Каждый текст (чанк / тезис) превращается в вектор путем усреднения векторов всех слов
- Размерность векторов: 300
- Все слова усредняются равномерно, включая стоп-слова
- Нет учета важности слов

### 2. SIF (Smooth Inverse Frequency) embeddings

Взвешенное усреднение векторов слов из той же модели fasttext:

- Редкие слова получают больший вес
- Частые слова (стоп-слова) получают меньший вес
- Используется `alpha = 1e-3` (параметр сглаживания)
- Учитывается частота слова в корпусе

---

## Pipeline

1. Текст очищается от HTML-тегов и спецсимволов
2. Разбивается на предложения (NLTK)
3. Предложения группируются в чанки по 3 с перекрытием 1
4. Для каждого чанка и тезиса вычисляются:
   - FastText эмбеддинг (среднее по словам)
   - SIF эмбеддинг (взвешенное среднее)
5. Считается косинусная близость между чанками и тезисами
6. Для каждого чанка берется максимальная близость к любому тезису
7. Coverage = среднее максимальных близостей

---

## Используемые модели

| Модель | Что дает |
|---|---|
| **fasttext** | Векторы слов (300 измерений) для русского языка |
| **SIF** | Взвешенное усреднение векторов fasttext |

## Результаты (по 49 статьям)

| Метод | Среднее | Медиана | Std | Min | Max |
|---|---|---|---|---|---|
| **FastText** | **0.8183** | 0.8239 | 0.0405 | 0.7278 | 0.9035 |
| **SIF** | 0.7169 | 0.7181 | 0.0637 | 0.5590 | 0.8442 |

### Сравнение

| Показатель | Значение |
|---|---|
| Корреляция между методами | 0.6524 |
| Средняя разница | 0.1026 |
| FastText > SIF | в **48** статьях |
| SIF > FastText | в **1** статье |

---

## Выводы

1. **FastText дает более высокое покрытие**, чем SIF (0.818 против 0.717). Разница ~0.10.

2. **FastText стабильнее** - стандартное отклонение 0.040 против 0.064 у SIF.

3. **SIF более чувствителен к содержанию** - шире размах значений.

4. **FastText дает оптимистичную оценку**, потому что усредняет все слова, включая стоп-слова, которые есть везде и сближают векторы.

5. **SIF дает более реалистичную оценку**, потому что почти обнуляет стоп-слова и дает больший вес смысловым словам.
